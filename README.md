# SK B2C Warehouse

STYLEKOREAN_NJ / MOIDA — Warehouse Management System

## Features
- Order tracking with real-time status (Picking → Inspection → Palletizing)
- Multi-worker support per order
- KPI dashboard
- Manager panel with password protection
- Google Sheets backend via Apps Script

## Setup
1. Deploy Apps Script (`Code.gs`) to Google Sheets
2. Update `API_URL` in `index.html` if needed
3. Deploy via GitHub Pages

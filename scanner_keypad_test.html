스캐너 키패드 테스트 (운영 앱과 무관 — 아무것도 저장 안 함)

워크폰에서 열어서 아래 A~D 칸을 하나씩 테스트하고, 맨 아래 "결과 요약"을 캡처해서 보내주세요.
테스트 방법 (칸마다 똑같이)
  1. 칸을 손가락으로 한 번 탭 (커서가 들어가게)
  2. 화면 위 띠가 "키패드 숨김"(초록)인지 "키패드 표시됨"(빨강)인지 확인
  3. 그 상태에서 실제 스캐너로 바코드를 스캔 (2~3번)
  4. 칸 아래 회색 박스에 입력이 들어왔는지 확인 — 값이 찍히면 ✅
  5. 키패드가 빨강으로 뜨면, 그 칸은 "키패드 안 숨겨짐"입니다
키패드 숨김
A. 지금 운영 앱과 동일 (기준)대기
아무 처리 없음 — 스캔은 되지만 키패드가 뜨는 현재 상태
B. 포커스 순간 잠깐 readonly 후 해제대기
탭하면 키패드가 안 뜨고 커서만 유지, 해제 후에도 입력창으로 동작해야 함 (스캔 후 자동 재포커스 포함)
C. readonly 유지 + 화면 전체에서 스캔 키 입력 직접 받기대기
입력창은 읽기전용(키패드 절대 안 뜸), 스캐너가 보내는 키 입력을 페이지가 직접 수신
D. inputmode="none" (이미 실패 확인된 방식 — 비교용)대기
키패드는 안 뜨지만 스캔이 안 들어가는 것으로 확인된 방식. 같은 기기에서 결과 비교용
